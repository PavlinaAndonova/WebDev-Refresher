# Big Planetarium Website – Reflection

I found creating the website structure using HTML and styling the pages with CSS relatively straightforward. Using semantic HTML elements, a consistent navigation menu and a shared stylesheet helped me maintain a clear structure and consistent design across the website. I also enjoyed creating individual pages for the eight planets, each with its own colour theme, images and interesting facts. Adding interactive features using JavaScript, such as showing and hiding facts and displaying pop-up information, made the website more engaging.

The most challenging part was implementing JavaScript interactivity and ensuring the website was accessible and responsive. I needed to consider how the layout would appear on different screen sizes and how users would navigate between pages. Testing the website using browser developer tools helped me check the layout on desktop and mobile screens and verify that the interactive features worked correctly. I also identified areas that could be improved, including keyboard navigation, ARIA labels and image optimisation.

During Web Development II, I would like to improve my JavaScript skills, particularly DOM manipulation and using event listeners instead of inline event handlers. This would help me write cleaner code and develop more interactive, accessible and dynamic websites. I would also like to gain a better understanding of accessibility guidelines and responsive design so I can create websites that provide a better experience for all users.
